# Logos

The Sieve symbol: a graphite tile with three teal bars narrowing to one lilac dot. The wordmark is Geist, "Marktplaats" 400 in `text-2` and "Watcher" 600 in `text`, outlined to paths (no font needed).

- `symbol.svg`, `favicon.svg`: tile `#1b1a18`, bars `#4fd1bf`, dot `#bca8ff`. For light grounds.
- `symbol-on-dark.svg`: tile lifted to `#2b2926` with a hairline, for dark grounds.
- `symbol-mono-black.svg` / `symbol-mono-white.svg`: one colour, bars and dot knocked out of the tile.
- `lockup-horizontal-*`, `lockup-stacked-*`: light (ink `#1b1a18` / `#5b5751`), dark (`#ece9e4` / `#a9a49c`), mono black, mono white. Clear space is built in at 1/4 of the symbol width.
- `wordmark-light.svg` / `wordmark-dark.svg`: the wordmark alone.
- `favicon-16.png` is drawn on a 16px grid (bars 10/6/4px, 2px high); use it below 24px. `favicon-32.png` and `favicon.svg` from 24px up.
- `apple-touch-icon.png` (180, full-bleed, iOS masks it), `icon-512.png` (transparent, rounded tile), `icon-512-maskable.png` (full-bleed; content inside the 80% safe circle).
- These are the prototype. The final mark gets refined in GPT Images, then re-vectorised.
