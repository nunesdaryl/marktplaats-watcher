# Pill

Small status labels: the beta pill, a watch's schedule with its status dot, and tab-bar counts.

- 24px high, `radius-pill`, `text-xs` 500. Neutral: `fill` / `text-2`. Accent: `accent-soft` / `accent`. Tag: `tag` / `tag-ink`, used only for Watch mode.
- **Status dot:** 6–8px. Active is `great`; paused is a 1.5px `text-3` ring (the shape change carries the meaning, not only the colour).
- **Count:** 18px, `accent` / `accent-ink`, Geist Mono 11px.
- Pills are not interactive; for anything clickable use a Chip.
