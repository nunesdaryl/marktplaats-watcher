# Toast

A short confirmation, inverted: `text` fill with `bg` text, `radius-lg`, `shadow`, `text-md` 500 and a 18px `great` check.

- Bottom centre, above the tab bar on phones. It fades in over `--dur`, stays 4s and uses `role="status"`.
- One at a time. No actions inside; errors belong in the page, not in a toast.
